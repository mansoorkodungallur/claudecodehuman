The RTFC Framework

RTFC is a systematic approach to crafting powerful prompts. It stands for: Role, Task, Format, Constraints. Master this and you'll write better prompts than 90% of users.

🎭

R - Role

Define who ChatGPT should be. Giving it a role provides context and expertise.

Examples:
  • "Act as an experienced software engineer..."
  • "You are a creative marketing consultant..."
  • "Respond as a patient tutor..."
📋

T - Task

Clearly specify what you want done. Be specific about the action and outcome.

Examples:
  • "Write a blog post about..."
  • "Debug this code and explain the errors..."
  • "Analyze this data and identify trends..."
📄

F - Format

Specify how you want the output structured. This ensures usable results.

Examples:
  • "Format as a numbered list..."
  • "Create a table with columns: X, Y, Z..."
  • "Write in markdown with headers and code blocks..."
⚙️

C - Constraints

Set boundaries: length, style, what to include/exclude, tone, etc.

Examples:
  • "Keep it under 300 words..."
  • "Use simple language, avoid jargon..."
  • "Focus only on solutions after 2020..."
💡 Pro Insight: You don't always need all four elements, but having them in mind ensures you don't miss critical details. For complex tasks, RTFC is your checklist.

Advanced Prompt Engineering Patterns

Beyond RTFC, professional prompt engineers use specific patterns to solve different types of problems. Master these four core patterns:

🔗

Chain-of-Thought (CoT)

When to use: Complex reasoning, math problems, multi-step analysis

How it works: Ask ChatGPT to show its reasoning step-by-step

Example: "Solve this problem step-by-step, showing your reasoning at each stage: If a train travels 120 km in 1.5 hours, then stops for 30 minutes, how long will it take to complete a 400 km journey? Think through this systematically."
✅ Benefit: More accurate answers, easier to spot errors, educational value
📚

Few-Shot Learning

When to use: Specific formats, style matching, pattern recognition

How it works: Provide 2-3 examples, then ask for more in the same style

Example: "Convert these sentences to tweet format: Example 1: Input: Artificial intelligence is transforming healthcare through predictive diagnostics Output: 🏥 AI is revolutionizing healthcare! Predictive diagnostics are saving lives. #HealthTech #AI Example 2: Input: Remote work has increased productivity for many companies Output: 💼 Remote work = ⬆️ productivity! Companies are thriving. #FutureOfWork #RemoteLife Now convert this: Input: Renewable energy adoption is accelerating globally"
✅ Benefit: Consistent formatting, style matching, reduced ambiguity
🎭

Role-Playing

When to use: Expert advice, specific perspectives, creative scenarios

How it works: Assign ChatGPT a detailed persona with expertise and viewpoint

Example: "You are a senior UX designer with 10 years of experience at top tech companies. You specialize in mobile app design and have strong opinions about minimalist interfaces. Review this app concept: [describe concept] Provide a critical analysis focusing on user experience, including 3 specific improvements and your reasoning for each."
✅ Benefit: Domain-specific expertise, consistent perspective, detailed analysis
🔄

Iterative Refinement

When to use: Complex outputs, when first attempt isn't quite right

How it works: Build on previous responses with specific improvement requests

Example: Prompt 1: "Write a product description for noise-cancelling headphones" [Review response] Prompt 2: "Rewrite this focusing more on the benefits for remote workers. Make it more conversational." [Review again] Prompt 3: "Perfect, but reduce it to 150 words and add a compelling call-to-action."
✅ Benefit: Progressively better results, fine-tuned control, collaborative feel
💎 Pro Tip: Combine patterns! For example, use Chain-of-Thought + Role-Playing: "You are an expert financial advisor. Walk me through step-by-step how you would evaluate this investment opportunity..."

12 Use Case Deep Dives

Let's explore real-world applications across different domains. Each use case includes proven prompts and best practices.

Use Case 1: Code Generation

Effective Prompt: "Act as an experienced Python developer. Write a function that: - Takes a list of dictionaries as input - Filters items where 'status' is 'active' - Sorts by 'timestamp' in descending order - Returns only the top 10 results Include: - Type hints - Docstring - Error handling for edge cases - 2-3 test cases"

Use Case 2: Code Review & Debugging

Effective Prompt: "Review this JavaScript code for: 1. Potential bugs 2. Performance issues 3. Security vulnerabilities 4. Best practice violations [paste code here] For each issue found: - Explain what's wrong - Show the corrected code - Explain why your version is better"

Use Case 3: Documentation Writing

Effective Prompt: "Generate comprehensive documentation for this API endpoint: [paste code/endpoint details] Include: - Description of what it does - Parameters (name, type, required/optional, description) - Return values - Example request/response - Possible error codes - Usage notes or warnings Format in Markdown."

Use Case 4: Content Creation

Effective Prompt: "Write a 600-word blog post about [topic]. Target audience: [describe audience] Tone: [professional/casual/enthusiastic] Goal: [educate/persuade/entertain] Structure: - Hook (compelling opening) - 3 main points with examples - Actionable conclusion Include: - SEO-friendly subheadings - Natural keyword integration: [keywords] - Call-to-action at end"

Use Case 5: Editing & Proofreading

Effective Prompt: "Edit the following text for: - Grammar and spelling errors - Clarity and conciseness - Tone consistency (keep it [professional/casual]) - Flow and readability Provide: 1. The edited version 2. A summary of major changes made 3. Suggestions for further improvement Text to edit: [paste text here]"

Use Case 6: Email Composition

Effective Prompt: "Write a professional email with: Context: [describe situation] Recipient: [their role/relationship to you] Purpose: [what you want to achieve] Tone: [formal/friendly professional] Key points to cover: 1. [point 1] 2. [point 2] 3. [point 3] Keep it concise (under 200 words) and include a clear call-to-action."

Use Case 7: Data Analysis

Effective Prompt: "Analyze this dataset and provide insights: [paste data or describe dataset] Focus on: - Key trends and patterns - Anomalies or outliers - Correlations between variables - Actionable recommendations Present findings as: 1. Executive summary (3-4 sentences) 2. Detailed analysis with specific numbers 3. Visualizations needed (describe what charts would help) 4. Next steps"

Use Case 8: Meeting Summarization

Effective Prompt: "Summarize these meeting notes: [paste transcript or notes] Format as: - Key Decisions Made (bullet points) - Action Items (person responsible, deadline, task) - Important Discussion Points - Next Meeting Date/Topics Keep it scannable and under 300 words."

Use Case 9: Competitive Analysis

Effective Prompt: "Create a competitive analysis comparing: Our product: [describe] Competitor 1: [name and describe] Competitor 2: [name and describe] Competitor 3: [name and describe] Analyze: - Feature comparison (table format) - Pricing strategy - Target market differences - Unique selling propositions - Strengths and weaknesses of each Conclude with 3 strategic recommendations for our positioning."

Use Case 10: Concept Explanation

Effective Prompt: "Explain [complex concept] at three different levels: 1. ELI5 (Explain Like I'm 5): Simple analogy, no technical terms 2. High School: More detail, introduce key terminology 3. College/Professional: Technical depth, nuances, real applications For each level: - Use relevant examples - Build on the previous explanation - End with a 'check your understanding' question"

Use Case 11: Study Guide Creation

Effective Prompt: "Create a study guide for [topic/subject]: Content to cover: [paste syllabus, chapter, or topic list] Include: - Key concepts with definitions - Important formulas/rules (if applicable) - Practice questions (5 easy, 5 medium, 2 hard) - Common mistakes to avoid - Memory techniques or mnemonics - Additional resources for deeper learning Format for easy scanning and review."

Use Case 12: Practice Problem Generation

Effective Prompt: "Generate 10 practice problems for [subject/topic]. Requirements: - Difficulty: [beginner/intermediate/advanced] - Type: [multiple choice/short answer/practical application] - Focus areas: [list specific concepts] For each problem: - Clear question - Worked solution showing steps - Explanation of key concepts used - Related problems for more practice"
